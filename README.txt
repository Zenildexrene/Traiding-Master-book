DÉPLOIEMENT SUR VERCEL
1. Mets ce dossier dans un dépôt GitHub (ou utilise la CLI : npm i -g vercel, puis "vercel --prod").
2. Dans Vercel > Settings > Environment Variables, ajoute :
     ACCESS_CODE = ton code d'accès
3. Redéploie. Ouvre l'URL, connecte-toi, entre le nom du client, télécharge.
Pour changer de code : modifie ACCESS_CODE et redéploie. Pour changer le PDF : remplace assets/manuel.pdf.
